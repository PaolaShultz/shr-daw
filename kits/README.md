# Bundled SHR Drums kits

Only the four `.shrkit` package directories named in `cleared-kits.txt` are
part of the public SHR-DAW package. Acid and Electronic House are original,
fully modeled CC0 kits with no audio samples. Big Rock and Experimental Noise
use selected MuldjordKit recordings under CC BY 4.0; each package includes the
upstream licence and source README required for redistribution.

Every kit's `manifest.json` records its exact content licence, authorship,
source, modification notes, and source hashes. The public provenance summary
and upstream links are in [`../THIRD_PARTY.md`](../THIRD_PARTY.md). Do not add a
local or downloaded kit to the allowlist until its redistribution terms and
complete package contents have been reviewed.
